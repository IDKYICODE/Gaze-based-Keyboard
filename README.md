# Gaze-Based Keyboard

Eye-tracking-based keyboard input system. Lets users type and interact without physical input devices — purely through gaze.

## Contents

| Notebook | Description |
|----------|-------------|
| `MPS/experiment.ipynb` | Core gaze tracking experiments |
| `MPS/game.ipynb` | Game interface controlled via gaze |
| `MPS/mcq.ipynb` | MCQ answering through gaze selection |

## Requirements

- Python 3.x
- Jupyter Notebook / JupyterLab
- Eye tracking hardware or compatible webcam-based tracker

## Usage

```bash
jupyter notebook MPS/experiment.ipynb
```

Open any notebook in the `MPS/` folder to explore the different interaction modes.
